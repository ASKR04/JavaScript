## Repository Goal

Each project in this repository is designed to be useful, documented, and structured like a real engineering artifact. The focus is on meaningful product ideas, clean UI, readable architecture, and commits that show steady software engineering progress.

## Delivery Workflow

Feature pull requests target `aug_release`, where the repository-wide **Project quality** workflow discovers and verifies every Node project. Promotion from `aug_release` to `main` happens separately after a deployment date and time are agreed and explicit merge approval is given.

See the [release workflow](./docs/release-workflow.md) for branch roles, quality gates, and the deployment promotion checklist.
